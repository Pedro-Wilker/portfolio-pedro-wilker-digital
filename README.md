# 🇧🇷 Portfólio Pedro Wilker Digital

Bem-vindo ao meu **portfólio pessoal profissional**.  
Este projeto foi desenvolvido para representar minha presença digital como **Desenvolvedor Full Stack**, reunindo meus projetos, habilidades e identidade profissional em uma interface moderna, rápida e responsiva.

🎯 **Objetivo:** apresentar meu trabalho para recrutadores, empresas e clientes de forma clara, elegante e profissional.

---

## ✨ Sobre mim

Sou **Pedro Wilker**, Desenvolvedor Full Stack com experiência na criação de aplicações web modernas, escaláveis e focadas em experiência do usuário.  
Atuo com tecnologias como **Java, TypeScript, React, Node.js, Spring Boot e Python**, desenvolvendo sistemas completos do back-end ao front-end.

Este portfólio foi criado para centralizar:
- Meus principais projetos
- Minhas competências técnicas
- Minha identidade profissional

## 📁 Estrutura do Projeto

```text
├── public/              # Arquivos públicos e assets
├── src/                 # Código-fonte da aplicação
│   ├── components/      # Componentes reutilizáveis
│   ├── pages/           # Seções do site
│   ├── assets/          # Imagens e ícones
│   └── styles/          # Estilos globais
├── index.html           # Ponto de entrada
├── tailwind.config.ts   # Configuração do Tailwind
├── vite.config.ts       # Configuração do Vite
└── package.json         # Dependências e scripts
```
